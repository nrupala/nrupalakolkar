Fixing a Firefox-only SSL error by switching off Cloudflare ECH
2026-09-26
Firefox refused the site with SSL_ERROR_ECH_RETRY_WITHOUT_ECH; Chrome loaded it. The cause: inconsistent ECH keys in the DNS HTTPS record. The fix: a one-time, least-privilege Cloudflare API token — created, used once, deleted.
