Fixing a Firefox-only SSL error by switching off Cloudflare ECH
2026-09-26
Firefox refused the site with SSL_ERROR_ECH_RETRY_WITHOUT_ECH while Chrome sailed through. The cause was flapping ECH keys in the DNS HTTPS record — and the fix was a one-time, least-privilege Cloudflare API token: create, use once, delete.
