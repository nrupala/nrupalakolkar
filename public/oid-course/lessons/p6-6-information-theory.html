6.6 Information Theory for Engineers

Bridge lesson — connecting OID core to AI, technology, and electrical systems

Why this matters for AI, technology, and electrical systems

This is your home turf, taught at full rigor. Shannon's theory is the mathematical foundation of every communication system you will ever touch — and, less famously, the hidden substrate of modern machine learning: cross-entropy loss is a KL divergence, variational inference is a coding argument, and the information bottleneck reframes deep learning as lossy compression. This lesson states the core theorems properly — source coding, channel coding, rate–distortion — with proof sketches that show why they hold, then draws the lines into ML that make the theory do double duty.

Learning objectives

  • Define entropy, conditional entropy, mutual information, and KL divergence, and prove their basic properties (nonnegativity, chain rule, data processing inequality).
  • State Shannon's source coding and channel coding theorems and sketch the AEP/random-coding arguments behind them.
  • Compute the capacity of a binary symmetric channel and the entropy of a discrete source, numerically.
  • State the rate–distortion theorem and explain lossy compression as its operational meaning.
  • Derive cross-entropy loss and the variational ELBO as information-theoretic quantities.

Core content

Entropy: the measure of uncertainty

For a discrete random variable X with pmf p(x), the entropy is H(X) = −Σ p(x) log p(x), in bits when log is base 2. Operational meaning: the expected surprise of an outcome, and — by the source coding theorem below — the fundamental limit of compression. Key properties: H(X) ≥ 0 with equality iff X is deterministic; H(X) ≤ log |𝒳| with equality iff X is uniform (uncertainty is maximized by uniformity — prove via Jensen, since log is concave); the chain rule H(X,Y) = H(X) + H(Y|X), where conditional entropy H(Y|X) = E[−log p(Y|X)] is the remaining uncertainty in Y after observing X. Conditioning reduces entropy: H(Y|X) ≤ H(Y), because information cannot hurt on average — though a particular observation can mislead, the expectation never does.

Mutual information and the data processing inequality

Mutual information I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X) = H(X) + H(Y) − H(X,Y) measures the reduction in uncertainty about X from observing Y — the information they share. It is symmetric, nonnegative, and zero iff X and Y are independent. The crown jewel is the data processing inequality: if X → Y → Z forms a Markov chain (Z depends on X only through Y), then I(X;Z) ≤ I(X;Y). Proof sketch: expand I(X;Y,Z) two ways via the chain rule; Markovity kills I(X;Z|Y) = 0, leaving I(X;Y) = I(X;Z) + I(X;Y|Z) ≥ I(X;Z). No clever post-processing of Y can manufacture information about X that Y did not contain. For the engineer: no equalizer, decoder, or neural post-processor can beat the information already captured at its input — a hard ceiling on every receiver chain and every feature pipeline.

KL divergence, cross-entropy, and maximum likelihood

The Kullback–Leibler divergence D_KL(p || q) = Σ p(x) log(p(x)/q(x)) = E_p[log(p/q)] measures the excess cost of assuming q when the truth is p. It is nonnegative — D_KL(p||q) ≥ 0 with equality iff p = q — by Jensen's inequality applied to the convex −log (this one inequality is the engine of half of information theory). It is not symmetric and not a metric; treat it as a directed "distance." Cross-entropy H(p,q) = −Σ p(x) log q(x) decomposes as H(p,q) = H(p) + D_KL(p||q): the irreducible uncertainty plus the penalty for using the wrong model. Now the ML connection: given data x₁…xₙ from unknown p, maximizing the likelihood Π q_θ(xᵢ) is exactly minimizing (1/n)Σ −log q_θ(xᵢ), the empirical cross-entropy — i.e., minimizing D_KL(p̂||q_θ) where p̂ is the empirical distribution. Maximum likelihood is minimum KL divergence to the empirical distribution. Every classifier you train with cross-entropy loss is doing information-theoretic projection, whether you call it that or not.

Source coding theorem: entropy is the compression limit

Theorem (Shannon, source coding). For i.i.d. source X, n outcomes can be encoded with expected length per symbol approaching H(X) arbitrarily closely, and no scheme achieves expected length below H(X).

Why it holds — the asymptotic equipartition property (AEP): among the |𝒳|^n possible sequences, probability concentrates on a typical set of roughly 2^{nH(X)} sequences, each with probability ≈ 2^{−nH(X)}. Encode only the typical set (index it with nH(X) bits); atypical sequences occur with vanishing probability and their contribution to expected length vanishes. The converse: any code with expected length L per symbol satisfies L ≥ H(X) − o(1), because entropy bounds the expected code length from below via Kraft's inequality and Jensen. Huffman coding achieves within 1 bit of H(X) per symbol; arithmetic coding and ANS close the gap. For the EE engineer: this is why your modem's constellation, your codec's bitrate, and your file compressor all orbit the same number — entropy is not a metaphor for compressibility, it is compressibility.

Channel coding theorem: capacity is the reliable-transmission limit

Theorem (Shannon, channel coding). For a discrete memoryless channel, there exist codes transmitting reliably (error probability → 0) at any rate R < C, and no reliable communication is possible at R > C, where capacity C = max_{p(x)} I(X;Y).

Why it holds — random coding: generate a codebook at random from p(x); decode by joint typicality (received y is jointly typical with exactly one codeword w.h.p.). The error analysis shows the probability that a wrong codeword looks jointly typical is ≈ 2^{−nI(X;Y)}, so as long as the number of codewords 2^{nR} satisfies R < I(X;Y), the union bound drives error to zero. Maximize over input distributions for C. The converse uses Fano's inequality: the residual uncertainty about the message given the received signal bounds the error probability away from zero when R > C. Modern capacity-approaching codes — turbo, LDPC, polar — are constructive realizations of this random-coding promise; 5G's control channels use polar codes, the first explicit family proven to achieve capacity. The worked example below computes the BSC capacity in closed form.

Rate–distortion: the theory of lossy compression

Theorem (Shannon, rate–distortion). For source X and distortion measure d, the minimum rate needed to achieve expected distortion ≤ D is R(D) = min_{p(x̂|x): E[d] ≤ D} I(X;X̂).

Operational meaning: lossy compression is a choice of how much information to preserve. R(D) is the fewest bits per symbol that suffice for distortion D; it is convex and decreasing in D, with R(0) = H(X) (lossless limit) for most sources. Every JPEG quantization table, every neural audio codec, every "quality vs bitrate" knob is navigating an empirical R(D) curve. The Blahut–Arimoto algorithm computes R(D) numerically. Conceptually, rate–distortion is the bridge to representation learning: an autoencoder with a bottleneck is minimizing a Lagrangian of rate (bottleneck capacity) and distortion (reconstruction error) — the information bottleneck principle (Tishby) makes this precise by trading I(X;Z) against I(Z;Y) for task-relevant compression.

Information theory inside machine learning

Three more connections close the loop with Lessons 6.2–6.3. Variational inference: the ELBO from Lesson 6.3, ELBO = E[log p(x|z)] − D_KL(q(z|x)||p(z)), is a coding argument — the KL term is the extra bits paid for using the approximate posterior q instead of the prior p (bits-back coding makes this literal). Mutual information estimation: representation learning increasingly optimizes I-based objectives (InfoNCE in contrastive learning lower-bounds mutual information), though MI is notoriously hard to estimate in high dimensions — the Donsker–Varadhan variational bound is powerful but high-variance, so treat "we maximize MI" claims with the skepticism Lesson 6.5 recommends. Minimum description length (Lesson 6.2): model selection as compression — the best model minimizes (bits for the model) + (bits for the data given the model) — is Shannon's source coding theorem applied to the scientific process itself. Information theory is not adjacent to ML; at the foundations, it is ML's accounting system.

Worked examples

Example 1: Capacity of a binary symmetric channel with p = 0.1

A BSC flips each bit independently with probability p = 0.1. Capacity: C = 1 − H(p) bits per use, achieved by uniform inputs (symmetry). Compute H(0.1) = −0.1·log₂(0.1) − 0.9·log₂(0.9) = 0.1 × 3.322 + 0.9 × 0.152 = 0.332 + 0.137 = 0.469 bits. So C = 1 − 0.469 = 0.531 bits per channel use. Interpretation: a 10 percent bit-flip rate destroys 47 percent of each bit's information-carrying capacity — yet 0.531 reliable bits per use remain achievable with proper coding (LDPC/polar), versus 0 with naive uncoded transmission at any rate above zero error tolerance. Sanity checks: p = 0 → C = 1 (perfect channel); p = 0.5 → C = 0 (output independent of input — the channel is useless, and note flipping all bits when p > 0.5 recovers capacity 1 − H(1−p)).

Example 2: Source coding — entropy vs Huffman on a 4-symbol source

Source symbols with probabilities: A: 0.5, B: 0.25, C: 0.125, D: 0.125. Entropy: H = −0.5·log₂0.5 − 0.25·log₂0.25 − 2×0.125·log₂0.125 = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bits/symbol. Huffman code: A → 0 (1 bit), B → 10 (2 bits), C → 110, D → 111 (3 bits). Expected length: 0.5×1 + 0.25×2 + 0.125×3 + 0.125×3 = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bits — exactly H(X), because the probabilities are dyadic. Fixed-length coding would need 2 bits/symbol: entropy saves 12.5 percent here, and the saving grows with source skew. This is the source coding theorem in miniature: H(X) is both the lower bound and (essentially) achievable.

Example 3: Cross-entropy loss as KL divergence, numerically

A 3-class fault classifier outputs q = (0.7, 0.2, 0.1) for a sample whose true label is class 1, i.e., p = (1, 0, 0). Cross-entropy loss: H(p,q) = −Σ p log q = −log₂(0.7) = 0.515 bits. Since H(p) = 0 (p is deterministic), this equals D_KL(p||q) = 0.515 bits — the entire loss is the model's divergence from truth. If the model instead outputs q = (0.98, 0.01, 0.01): loss = −log₂(0.98) = 0.029 bits. Note the asymmetry: swapping roles, D_KL(q||p) is infinite (q puts mass where p has none) — KL punishes confidently-wrong predictions superlinearly, which is why cross-entropy training is so sensitive to mislabeled data. Label smoothing (p = (0.9, 0.05, 0.05)) caps this penalty — a regularization with a clean information-theoretic reading.

Example 4: Data processing inequality on a receiver chain

Transmitted bits X → received waveform Y (through a noisy channel) → equalizer output Z → decoder decision Ŵ. By the data processing inequality, I(X;Ŵ) ≤ I(X;Z) ≤ I(X;Y): no stage recovers information lost earlier. Suppose the channel delivers I(X;Y) = 0.8 bits/use but a suboptimal equalizer keeps only I(X;Z) = 0.6. No decoder — however sophisticated, including a neural one — can exceed 0.6 bits/use of mutual information with the message; the 0.2-bit loss at the equalizer is irrecoverable. Engineering consequence: invest design effort at the information bottleneck of the chain (usually the front end), because downstream brilliance cannot compensate for upstream information destruction. The same inequality governs feature pipelines: I(label; features) caps every model trained on those features.

Key results to remember

  • H(X) = −Σ p log p: expected surprise; maximized by the uniform distribution; chain rule H(X,Y) = H(X) + H(Y|X); conditioning reduces entropy.
  • I(X;Y) = H(X) − H(X|Y): shared information; data processing inequality — X → Y → Z implies I(X;Z) ≤ I(X;Y); no post-processing creates information.
  • D_KL(p||q) ≥ 0 (Jensen), directed, not a metric; H(p,q) = H(p) + D_KL(p||q); maximum likelihood = minimizing KL to the empirical distribution.
  • Source coding theorem: n i.i.d. outcomes need ≈ nH(X) bits (AEP/typical set), and no scheme beats H(X) per symbol — entropy is compressibility.
  • Channel coding theorem: reliable communication iff R < C = max I(X;Y); random coding + joint typicality for achievability, Fano's inequality for the converse; BSC capacity = 1 − H(p).
  • Rate–distortion R(D) = min I(X;X̂) over E[d] ≤ D: lossy compression as chosen information preservation; autoencoders and the information bottleneck live on this curve.
  • ML is information theory in disguise: cross-entropy loss is KL, the VAE ELBO is a coding argument (bits-back), MDL is source coding applied to model selection.
  • Design rule: find the information bottleneck of your chain (receiver, feature pipeline) and spend effort there — downstream stages cannot recover lost mutual information.

Check your understanding

  1. Prove from Jensen's inequality that D_KL(p||q) ≥ 0.
    Answer

    D_KL(p||q) = E_p[−log(q/p)] ≥ −log(E_p[q/p]) = −log(Σ p·q/p) = −log(Σ q) = −log 1 = 0, using convexity of −log. Equality iff q/p is constant a.s., i.e., p = q.

  2. A channel flips bits with probability 0.2. What is its capacity, and what does the number mean operationally?
    Answer

    C = 1 − H(0.2) = 1 − 0.722 = 0.278 bits per use. Any rate below 0.278 is achievable with arbitrarily small error (via LDPC/polar-type codes); no coding scheme communicates reliably above it.

  3. Why can a neural decoder never outperform the mutual information at the equalizer output?
    Answer

    Data processing inequality: X → Y → Z → Ŵ is a Markov chain, so I(X;Ŵ) ≤ I(X;Z). The decoder only sees Z; information about X not present in Z cannot be created by processing.

  4. Show that minimizing cross-entropy loss is equivalent to maximum likelihood estimation.
    Answer

    MLE maximizes Π q_θ(xᵢ), i.e., maximizes (1/n)Σ log q_θ(xᵢ) = −(empirical cross-entropy). Since empirical cross-entropy = H(p̂) + D_KL(p̂||q_θ) and H(p̂) is constant in θ, minimizing cross-entropy minimizes D_KL(p̂||q_θ) — equivalently maximizes likelihood.

  5. A lossy compressor offers 0.5 bits/symbol at distortion D₁ and 1.0 bits/symbol at distortion D₂ < D₁. Which point lies closer to the R(D) curve, and what does the curve's convexity imply about the tradeoff?
    Answer

    Neither dominance is decidable from the two points alone — each is evaluated against R(D) at its own D; closeness to the curve measures optimality. Convexity means diminishing returns: each extra bit buys less distortion reduction, so the marginal value of bitrate falls as quality rises.
