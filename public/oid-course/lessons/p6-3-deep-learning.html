6.3 Deep Learning

Doctoral course basis: Deep Learning for Data Science

Why this matters for AI, technology, and electrical systems

Deep learning is the representation-learning half of the CIS 5200 framing taken to its limit: instead of hand-designing features, you learn them as a composition of differentiable modules. For an EE/AI engineer this is home territory with new rules — circuits made of matrix multiplies, trained by a chain rule executed in reverse, whose generalization behavior still puzzles theorists. This lesson covers the architectures that won (CNNs, ResNets, LSTMs, transformers), the optimization that trains them, and the open questions a PhD student should be able to state precisely.

Learning objectives

  • Derive backpropagation as reverse-mode automatic differentiation on a computation graph.
  • Explain why Adam, batch normalization, dropout, and initialization schemes exist — what failure mode each fixes.
  • Compare CNNs, RNNs/LSTMs, and transformers: the inductive bias each encodes and the gradient problem each solves.
  • State the deep-learning generalization puzzle (overparameterization, double descent) and the current candidate explanations.
  • Describe VAEs, GANs, and diffusion models at the level of their training objectives.

Core content

Backpropagation: the chain rule, mechanized

A neural network is a directed acyclic computation graph of differentiable operations. Backpropagation (Rumelhart, Hinton and Williams 1986) is reverse-mode automatic differentiation: run the graph forward, caching intermediate values, then sweep backward applying the chain rule so that each node receives dL/d(node) — the gradient of the loss with respect to its output — and passes dL/d(input) = dL/d(node) × d(node)/d(input) to its parents. Reverse mode computes the full gradient of one scalar loss in a single backward pass, costing roughly the same as the forward pass — which is why it, not forward-mode or finite differences, trains networks with millions of parameters. Frameworks like PyTorch build this graph dynamically (autograd), so "implementing backprop" today means writing the forward pass correctly; the backward pass is derived, not hand-coded.

Activations, initialization, and the optimization stack

Sigmoid/tanh saturate: their derivatives vanish for large |x|, killing gradients in deep stacks — the historical reason deep nets stalled. ReLU (max(0,x)) has gradient 0 or 1, is cheap, and induces sparsity; its variants (leaky ReLU, GELU) smooth the kink. Initialization must preserve signal variance across layers: Xavier/Glorot initialization scales weights by 1/√(fan_in) for symmetric activations; He initialization uses √(2/fan_in) for ReLU, compensating for the half of units it zeroes. Get this wrong and activations explode or vanish exponentially with depth before training even starts.

Optimization for deep nets is stochastic by necessity: full-batch gradients are unaffordable, so SGD uses minibatch estimates, and momentum (a running average of gradients) damps the noise and accelerates along consistent directions. Adam (Kingma and Ba 2015) adds per-parameter adaptive learning rates from running estimates of the first and second gradient moments — fast and forgiving, the default that usually works. Two regularizers dominate practice. Dropout (Srivastava et al. 2014) randomly zeroes activations during training, preventing co-adaptation of units; at test time outputs are scaled by the keep probability so expectations match. Batch normalization (Ioffe and Szegedy 2015) normalizes each layer's inputs per minibatch, stabilizing the optimization landscape (the original "internal covariate shift" story has been refined, but the conditioning benefit is real) — at the cost of batch-size dependence that layer normalization avoids in transformers.

CNNs: translation invariance by construction

Convolutional networks (LeCun lineage; Krizhevsky, Sutskever and Hinton 2012, AlexNet) encode two inductive biases: locality (each unit sees a small patch) and weight sharing (the same filter slides across the input), giving translation equivariance with far fewer parameters than a dense layer. Pooling adds approximate translation invariance and reduces resolution. The parameter-count example below shows why this matters for images. ResNets (He et al. 2016) add skip connections, y = F(x) + x: the network learns residuals, and gradients flow unimpeded through the identity path — which is what finally allowed hundred-plus-layer training. Conceptually, a ResNet is an ensemble of paths of different depths, and the identity shortcut guarantees that adding layers cannot hurt representational capacity.

Sequences: RNNs, the vanishing gradient, LSTMs

Recurrent nets share weights across time steps, but backpropagation through time multiplies by the recurrent weight matrix at every step: gradients scale as roughly ρ^T where ρ is its spectral radius — exploding if ρ > 1, vanishing if ρ < 1. This is the vanishing/exploding gradient problem, and it is why vanilla RNNs cannot learn long-range dependencies. LSTMs (Hochreiter and Schmidhuber 1997) fix it architecturally: a cell state carried by gated additive updates (input, forget, output gates) lets gradients flow across time without repeated multiplication by the same matrix. GRUs simplify the gating. The lesson generalizes: when optimization fights the architecture, change the architecture — a theme transformers take further.

Attention and transformers

Scaled dot-product attention computes Attention(Q,K,V) = softmax(QKᵀ/√d)V: each query position takes a weighted average of value vectors, with weights from query–key similarity. Self-attention lets every token in a sequence attend to every other in O(n²) time — no recurrence, so fully parallelizable, with path length O(1) between any two positions (compare O(n) for RNNs). Multi-head attention runs several such mechanisms in parallel subspaces. Transformers (Vaswani et al. 2017, "Attention Is All You Need") stack self-attention with position-wise feedforward layers; since attention is permutation-invariant, positional encodings (sinusoidal or learned) inject order. The lineage: encoder-only BERT for understanding tasks, decoder-only GPT for generation, encoder–decoder for translation. The inductive bias is deliberately weak — almost everything is learned from data — which is why transformers are data-hungry and why pretraining plus fine-tuning (transfer learning) is the standard workflow.

Generative models: VAEs, GANs, diffusion

Variational autoencoders (Kingma and Welling 2014) maximize a lower bound on the log-likelihood: ELBO = E[log p(x|z)] − D_KL(q(z|x) || p(z)), trading reconstruction fidelity against keeping the approximate posterior near the prior — the KL term is the price of a usable latent space. GANs (Goodfellow et al. 2014) set up a minimax game: a generator fools a discriminator, the discriminator catches the generator; at equilibrium the generator matches the data distribution — powerful but unstable (mode collapse, non-convergence of simultaneous gradient descent on a game). Diffusion models learn to reverse a gradual noising process, predicting the added noise at each step; sampling iterates denoising. All three are now routinely conditioned (text-to-image is conditional diffusion), and all three inherit the optimization pathologies of their game or bound structure.

The generalization puzzle

Classical theory (Lesson 6.2) says capacity should hurt: yet overparameterized nets with millions more parameters than data points generalize well. The double descent curve refines the bias–variance picture: test error falls, rises near the interpolation threshold (parameters ≈ samples), then falls again deep into the overparameterized regime. Candidate explanations a PhD student should know: the implicit bias of SGD toward low-norm / max-margin solutions among all interpolators; the lottery-ticket / lazy-training view that wide nets barely move from initialization and behave like kernels; and flat-minima arguments linking sharpness to generalization. None is the full story — which is precisely why it remains research frontier, and why "just add parameters" is an empirical bet with increasingly good odds rather than a theorem.

Worked examples

Example 1: Backprop by hand on a tiny network

One input x = 2, one hidden ReLU unit h = max(0, w1·x) with w1 = 0.5, output ŷ = w2·h with w2 = 1.5, target y = 4, loss L = (ŷ − y)². Forward: h = max(0, 1.0) = 1.0; ŷ = 1.5; L = (1.5 − 4)² = 6.25. Backward: dL/dŷ = 2(ŷ − y) = −5. Then dL/dw2 = dL/dŷ · h = −5 · 1.0 = −5, and dL/dh = dL/dŷ · w2 = −7.5. Through the ReLU (active, derivative 1): dL/dw1 = dL/dh · x = −7.5 · 2 = −15. Gradient step with η = 0.01: w1 ← 0.5 + 0.15 = 0.65, w2 ← 1.5 + 0.05 = 1.55. Every deep network's training is this chain rule, mechanized over millions of nodes — reverse-mode AD just schedules the same computation efficiently.

Example 2: Parameter counting — dense vs convolutional on a 32×32 image

Input: 32×32 grayscale = 1024 pixels. A dense layer to 100 hidden units needs 1024 × 100 + 100 = 102,500 parameters. A convolutional layer with 16 filters of 5×5 needs 16 × 25 + 16 = 416 parameters — a 246× reduction — while preserving spatial structure and translation equivariance. This is the inductive-bias bargain: you trade the ability to learn arbitrary pixel permutations (which you do not need) for sample efficiency (which you do). For an EE engineer: it is exactly like replacing a full FIR filter bank with a structured one matched to the signal's symmetries.

Example 3: Self-attention on three tokens, concretely

Tokens with 2-D embeddings: e1 = (1, 0), e2 = (0, 1), e3 = (1, 1). Use Q = K = V = identity for clarity, d = 2, scale √2 ≈ 1.41. Query q1 = (1,0): raw scores q1·k = (1, 0, 1); scaled: (0.71, 0, 0.71); softmax ≈ (0.41, 0.17, 0.41). Output for token 1: 0.41·v1 + 0.17·v2 + 0.41·v3 = (0.82, 0.58) — a similarity-weighted mix of all tokens, computed in parallel with no recurrence. In a real transformer, learned Q/K/V projections and 8–96 heads let different heads specialize (one tracks syntax, another coreference), and stacking 12–100 such layers builds the contextual representations that make GPT work.

Example 4: Dropout's test-time scaling

A hidden unit outputs h = 4.0; dropout keeps it with probability p = 0.5 during training (else 0). Expected training output: 0.5 × 4.0 = 2.0. At test time dropout is off, so without correction the downstream layer would see 4.0 — double the expected training input, shifting every subsequent activation. Fix: scale test outputs by p (4.0 × 0.5 = 2.0), or equivalently use "inverted dropout" scaling training outputs by 1/p. The one-line correction is what makes dropout a valid ensemble average rather than a train/test distribution shift — a small instance of the discipline that separates working deep learning from alchemy.

Key results to remember

  • Backprop is reverse-mode automatic differentiation: one forward pass caching values, one backward pass applying the chain rule — gradient cost ≈ forward-pass cost.
  • ReLU + He initialization + Adam + batch norm/dropout is the standard stack because each fixes a specific failure: saturation, signal explosion/vanishing, slow ill-conditioned optimization, co-adaptation.
  • CNNs buy translation equivariance and parameter efficiency through locality and weight sharing; ResNet skip connections (y = F(x) + x) let gradients bypass depth.
  • RNN gradients scale as ρ^T (vanishing/exploding); LSTMs replace repeated multiplication with gated additive cell updates.
  • Self-attention: Attention(Q,K,V) = softmax(QKᵀ/√d)V — O(n²) parallel mixing with O(1) path length; positional encodings restore order; weak inductive bias ⇒ data-hungry ⇒ pretrain then fine-tune.
  • VAE: maximize ELBO = reconstruction − D_KL(q||p). GAN: minimax game converging (in theory) to the data distribution. Diffusion: learn to reverse noising.
  • Double descent: past the interpolation threshold, more parameters can reduce test error — classical capacity bounds are not the whole story; implicit bias of SGD is the leading explanation.
  • PyTorch workflow to fluency: tensors → autograd graphs → DataLoaders → training loops → GPU; never tune on the test set.

Check your understanding

  1. Why is reverse-mode (rather than forward-mode) automatic differentiation used to train neural networks?
    Answer

    A network maps millions of parameters to one scalar loss. Reverse mode computes the full gradient in one backward pass at roughly the forward-pass cost; forward mode would need one pass per parameter — millions of passes.

  2. A 200-layer plain feedforward net fails to train while a 200-layer ResNet trains fine. What exactly does the skip connection change about gradient flow?
    Answer

    With y = F(x) + x, the gradient dL/dx includes an identity term dL/dy · 1 that bypasses F's layers, so gradients propagate unattenuated regardless of depth; the network only needs to learn the residual F(x), and extra layers can default to near-identity.

  3. What goes wrong, numerically, if you forget test-time scaling with dropout?
    Answer

    Downstream layers receive inputs roughly 1/p times larger than the expected values seen during training, shifting all subsequent activations — a train/test distribution mismatch that degrades accuracy for no good reason.

  4. State the double-descent phenomenon and name one candidate explanation.
    Answer

    Test error decreases, increases near the interpolation threshold (parameters ≈ samples), then decreases again with further overparameterization. Candidate: SGD's implicit bias selects low-norm/max-margin interpolators that generalize despite huge capacity.

  5. Why do transformers need positional encodings?
    Answer

    Self-attention is permutation-invariant — it treats the input as a set. Positional encodings (sinusoidal or learned) inject sequence order so the model can distinguish "dog bites man" from "man bites dog."
