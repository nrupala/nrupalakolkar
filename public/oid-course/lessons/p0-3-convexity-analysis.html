0.3 Convexity and Real Analysis Primer

Bridge lesson — mathematical foundations for the OID PhD core

Why this matters for AI, technology, and electrical systems

Convexity is the dividing line between problems we can solve and problems we can only hope to solve: if a loss is convex, every local minimum is global, and gradient descent is guaranteed to converge — that is why linear regression, logistic regression, SVMs, and power-allocation problems in wireless systems all sit on convex foundations. Real analysis is the toolkit that makes those guarantees precise: continuity, compactness, and fixed-point theorems are what convergence proofs are written in. The OID PhD core — optimization (OIDD 9120), dynamic programming, stochastic models — assumes you can read and produce such arguments. This lesson gives you the definitions, the characterizations, and the proof patterns you will reuse for the rest of the course.

Learning objectives

  • Define convex sets and convex functions, and verify convexity using first- and second-order characterizations.
  • State and apply Jensen's inequality to expectations of convex functions, including a maximum-likelihood or risk-bound argument.
  • Define Lipschitz continuity and smoothness (Lipschitz gradients), and explain how each controls the behavior of gradient descent.
  • State the Banach fixed-point (contraction-mapping) theorem and the Bolzano–Weierstrass theorem, and sketch how they prove convergence and existence of minimizers.
  • Recognize the standard template of an optimization convergence proof: descent lemma, telescoping sum, limit.

Core content

Convex sets

A set C ⊆ R^n is convex if the entire line segment between any two of its points lies in C: for all x, y ∈ C and θ ∈ [0, 1], θx + (1 − θ)y ∈ C. Half-spaces {x : a^T x ≤ b}, Euclidean balls, the nonnegative orthant, the probability simplex {x ≥ 0 : Σx_i = 1}, and the positive semidefinite cone {X : X ⪰ 0} are all convex — and these are exactly the feasible regions of linear, quadratic, and semidefinite programs. Convexity is preserved under intersections (arbitrary), affine maps, and the perspective transform: that is why adding constraints of the form above never destroys the structure optimizers exploit. A point is an extreme point if it is not a strict convex combination of two others; the fundamental theorem of linear programming — optima occur at extreme points (vertices) — is a convexity statement. The convex hull of a set is the smallest convex set containing it, the intersection of all such sets.

Convex functions: definitions and characterizations

A function f is convex on a convex domain if its epigraph {(x, t) : t ≥ f(x)} is a convex set — equivalently, f(θx + (1 − θ)y) ≤ θf(x) + (1 − θ)f(y): the chord lies above the graph. Norms, x², e^x, x log x (on x > 0), the maximum of convex functions, and the log-sum-exp function log Σ e^{x_i} (the smooth softmax) are convex. Three characterizations are used constantly. First-order: for differentiable f, convexity is equivalent to f(y) ≥ f(x) + ∇f(x)^T (y − x) — the function lies above every tangent plane. This immediately gives the most-used fact in optimization: if ∇f(x*) = 0 at a point of a convex differentiable function, then x* is a global minimizer. Second-order: for twice-differentiable f, convexity is equivalent to a positive semidefinite Hessian ∇²f(x) ⪰ 0 everywhere — the link to Lesson 0.2's definiteness tests. Jensen's inequality is convexity for expectations: f(E[X]) ≤ E[f(X)]. Since x ↦ x² is convex, Jensen gives (E[X])² ≤ E[X²], i.e., Var(X) ≥ 0; since −log is convex, Jensen gives the nonnegativity of KL divergence, the foundation of the EM algorithm and variational inference.

Gradients, subgradients, and optimality

For smooth convex f, ∇f(x) = 0 is necessary and sufficient for global optimality. For nonsmooth convex f — absolute value, hinge loss, ReLU networks' losses, ℓ₁ penalties — the gradient is replaced by the subgradient: g is a subgradient at x if f(y) ≥ f(x) + g^T (y − x) for all y, and the set of all such g is the subdifferential ∂f(x). The ℓ₁ norm ‖x‖₁, which induces sparsity in lasso, compressed sensing, and sparse coding, has subdifferential at x_i = 0 equal to the whole interval [−1, 1] — this is why ℓ₁ regularization can set coefficients exactly to zero while ℓ₂ only shrinks them. Optimality becomes 0 ∈ ∂f(x). Directional derivatives extend the picture to non-convex settings, and the Clarke subdifferential generalizes further, but the convex subgradient calculus — sum rules, chain rules for affine compositions — covers everything in Part 1's estimation lessons.

Lipschitz continuity and smoothness

A function is L-Lipschitz if ‖f(x) − f(y)‖ ≤ L‖x − y‖ for all x, y: its slope is bounded, so it cannot jump or spike. A differentiable function is L-smooth if its gradient is L-Lipschitz: ‖∇f(x) − ∇f(y)‖ ≤ L‖x − y‖, which for twice-differentiable f is equivalent to ∇²f(x) ⪯ LI — bounded curvature. Smoothness yields the descent lemma: f(y) ≤ f(x) + ∇f(x)^T (y − x) + (L/2)‖y − x‖², a quadratic upper bound that is the entire engine of gradient-descent analysis. Taking the gradient step y = x − (1/L)∇f(x) in the descent lemma gives guaranteed per-step progress f(y) ≤ f(x) − (1/2L)‖∇f(x)‖² whenever the step size is at most 1/L — this is why "step size ≤ 1/L" appears in every convergence theorem, and why estimating L (e.g., the largest eigenvalue of X^T X for least squares) matters in practice. Strong convexity, f(y) ≥ f(x) + ∇f(x)^T(y − x) + (μ/2)‖y − x‖² with μ > 0, gives the complementary lower bound: it rules out flat directions and upgrades gradient descent from sublinear to linear (geometric) convergence, with rate governed by the condition number κ = L/μ.

Real analysis: the convergence toolkit

Optimization proofs rest on a handful of analysis theorems. A sequence is Cauchy if its terms eventually stay arbitrarily close; R^n is complete — every Cauchy sequence converges — so proving a sequence is Cauchy proves it has a limit. Bolzano–Weierstrass: every bounded sequence in R^n has a convergent subsequence; combined with continuity (preimages of convergent sequences converge), this proves existence of minimizers: a continuous f on a compact (closed and bounded) set attains its minimum — the Weierstrass extreme-value theorem. Monotone bounded sequences converge, which is how descent methods' objective values are shown to settle. The Banach fixed-point theorem: a contraction T with ‖T(x) − T(y)‖ ≤ ρ‖x − y‖, ρ < 1, on a complete space has a unique fixed point, found by iterating x_{k+1} = T(x_k) with geometric convergence at rate ρ. Gradient descent on a strongly convex smooth function is a contraction in a suitable norm; value iteration in dynamic programming is a contraction in the sup norm with ρ equal to the discount factor — the same theorem proves convergence of reinforcement-learning backups and of the Bellman recursion in OIDD 9300-style stochastic models.

The anatomy of a convergence proof

Most first-order convergence proofs follow one template. (1) Start from a descent or progress lemma, e.g., the smoothness bound giving f(x_{k+1}) ≤ f(x_k) − (1/2L)‖∇f(x_k)‖². (2) Relate the progress term to the optimality gap: for convex f, f(x_k) − f* ≤ ‖∇f(x_k)‖ · ‖x_k − x*‖ via the first-order characterization. (3) Telescope: summing the per-step bounds over k = 0 … K−1 collapses the sum into f(x_0) − f(x_K), yielding min_k ‖∇f(x_k)‖² ≤ O(1/K) or an O(1/K) rate on the gap for convex smooth functions. (4) Take limits using continuity/compactness arguments. Strong convexity replaces the gap bound by a contraction on ‖x_k − x*‖, giving linear convergence ‖x_k − x*‖² ≤ (1 − μ/L)^k ‖x_0 − x*‖². Recognizing this skeleton lets you read convergence results in papers as variations on one argument rather than as isolated miracles — a skill the PhD core's optimization and learning-theory courses assume from day one.

Worked examples

Example 1: Is the logistic loss convex?

Binary logistic regression minimizes f(w) = Σ_i log(1 + e^(−y_i w^T x_i)) with y_i ∈ {±1}. Each term is g(z) = log(1 + e^z) with z = −y_i w^T x_i. Since g″(z) = e^z/(1+e^z)² > 0, g is strictly convex in z; z is affine in w; and convex composed with affine is convex. A sum of convex terms is convex, so f is convex in w — logistic regression has no spurious local minima, and gradient descent with step size ≤ 1/L converges to the global optimum. The Hessian is X^T D X with D diagonal of g″(z_i) ≥ 0, hence PSD, confirming convexity by the second-order test from Lesson 0.2.

Example 2: Jensen's inequality and the EM algorithm

In a mixture model the log-likelihood log Σ_z p(x, z | θ) is a log of a sum — hard to maximize. Since log is concave, Jensen gives log Σ_z q(z) · [p(x,z|θ)/q(z)] ≥ Σ_z q(z) log[p(x,z|θ)/q(z)] for any distribution q over the latent z: the right side is the ELBO, a tractable lower bound. The EM algorithm alternates: the E-step sets q to the posterior p(z | x, θ) (tightening the bound), the M-step maximizes the bound in θ. Each step monotonically increases the true log-likelihood — Jensen's inequality is literally the convergence engine of EM, variational inference, and the Dempster–Laird–Rubin theory behind the statistical-inference skill.

Example 3: Contraction in a power-control iteration

In a wireless network, each transmitter updates its power by the Foschini–Miljanic rule p_i ← γ_i (Σ_{j≠i} G_{ij} p_j + η_i)/G_{ii}, targeting SINR γ_i. In vector form p ← T(p) with T(p) = D(Fp + η), where F has zero diagonal. When the spectral radius of DF is below 1, T is a contraction in a weighted max norm, so Banach's theorem guarantees a unique fixed point — the minimal feasible power vector — and geometric convergence from any starting powers. This is distributed power control in cellular systems, proved with the same theorem that proves value iteration converges in dynamic programming.

Example 4: Gradient descent rate on a quadratic

Minimize f(x) = ½x^T A x − b^T x with A PD, eigenvalues in [μ, L]. Gradient descent with step 1/L gives x_{k+1} − x* = (I − A/L)(x_k − x*), so ‖x_k − x*‖ ≤ (1 − μ/L)^k ‖x_0 − x*‖ — linear convergence with rate set by the condition number κ = L/μ. For a 2-D quadratic with eigenvalues 1 and 100, κ = 100 and the error shrinks by only ~1% per step along the flat direction: this is why feature normalization (which clusters eigenvalues) and preconditioning matter in practice. The descent lemma's quadratic upper bound with L = 100 is exactly what certifies the step size 1/100.

Key results to remember

  • Convex sets contain all segments between their points; half-spaces, balls, the simplex, and the PSD cone are the feasible regions of tractable optimization.
  • Convexity ⇔ function above its tangents (first order) ⇔ PSD Hessian (second order); for convex f, ∇f(x*) = 0 is necessary and sufficient for global optimality.
  • Jensen's inequality: f(E[X]) ≤ E[f(X)] for convex f — behind KL nonnegativity, the ELBO, and EM's monotone ascent.
  • Subgradients extend optimality to nonsmooth convex losses: 0 ∈ ∂f(x); the ℓ₁ subdifferential at zero is the interval [−1, 1], which is why ℓ₁ induces exact sparsity.
  • L-smoothness (Lipschitz gradient) gives the descent lemma and the step-size rule η ≤ 1/L; strong convexity (μ > 0) upgrades gradient descent to linear convergence with condition number κ = L/μ.
  • Banach fixed-point theorem: contractions on complete spaces converge geometrically to a unique fixed point — proves value iteration and distributed power-control convergence alike.
  • Bolzano–Weierstrass + continuity ⇒ a continuous function on a compact set attains its minimum (Weierstrass).
  • Convergence proofs follow a template: descent lemma → gap bound → telescoping sum → limit; strong convexity turns the template into a contraction.

Check your understanding

  1. Prove from the first-order characterization that if f is convex and differentiable with ∇f(x*) = 0, then x* is a global minimizer.
    Answer

    First-order convexity: f(y) ≥ f(x*) + ∇f(x*)^T(y − x*) for all y. With ∇f(x*) = 0 the right side is f(x*), so f(y) ≥ f(x*) for every y — x* is globally optimal.

  2. Use Jensen's inequality to show that the Kullback–Leibler divergence D_KL(p‖q) = E_p[log(p(X)/q(X))] is nonnegative.
    Answer

    D_KL(p‖q) = E_p[−log(q(X)/p(X))] ≥ −log(E_p[q(X)/p(X)]) by Jensen (since −log is convex) = −log(Σ_x q(x)) = −log 1 = 0, with equality iff p = q.

  3. A function is L-smooth. What step size does the descent lemma justify for gradient descent, and what per-step guarantee does it give?
    Answer

    Step size η ≤ 1/L; the descent lemma then gives f(x_{k+1}) ≤ f(x_k) − (1/2L)‖∇f(x_k)‖² — monotone decrease proportional to the squared gradient norm.

  4. Why does ℓ₁ regularization produce exactly-zero coefficients while ℓ₂ only shrinks them? Answer in terms of subgradients.
    Answer

    The ℓ₁ subdifferential at x_i = 0 is the whole interval [−1, 1], so 0 ∈ ∂f can hold with x_i exactly 0 (the penalty's "force" balances the loss gradient). The ℓ₂ penalty's gradient 2λx_i vanishes only at x_i = 0 in the limit, so coefficients shrink toward but generically never reach zero.
