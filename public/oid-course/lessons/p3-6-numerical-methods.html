3.6 Numerical Methods in Economics

Built from Wharton BEPP 9310: Numerical Methods in Economics

Why this matters for AI, technology, and electrical systems

The models in Lessons 3.1–3.5 rarely admit closed-form solutions once you leave textbook cases: dynamic games, rich heterogeneity, and realistic stochastic processes must be solved on a computer. The numerical toolkit — Bellman equations, value function iteration, discretization of Markov processes, simulation-based estimation — is the same machinery as reinforcement learning and stochastic control, developed in parallel by economists and engineers. If you can write a Bellman equation and iterate it to convergence, you already speak both languages; this lesson makes the translation explicit and adds the estimation side (how to take a computed model to data).

Learning objectives

  • Write a dynamic problem in recursive form (states, actions, transitions, Bellman equation) and verify the contraction property.
  • Implement value function iteration and policy iteration, and discretize AR(1) shocks with Tauchen/Rouwenhorst grids.
  • Choose among function-approximation methods (discretization, projection/collocation, perturbation) for a given problem.
  • Explain the nested fixed point, conditional choice probability, and simulated method of moments estimators.
  • Use QuantEcon workflows to solve and estimate a dynamic discrete-choice model end to end.

Core content

Dynamic programming: the Bellman equation

Start every computational problem by writing the recursive formulation before coding: states s, actions a, transition probabilities P(s′|s,a), per-period reward r(s,a), discount factor β < 1. The Bellman equation defines the value function V as the fixed point of the Bellman operator T: (TV)(s) = max_a { r(s,a) + β Σ_{s′} P(s′|s,a) V(s′) }. For the optimal-stopping / discrete-choice variant, V(s) = max_a { r(s,a) + ε_a + β E[V(s′)|s,a] } with choice-specific value functions v_a(s).

The key mathematical fact (Stokey, Lucas, and Prescott 1989): T is a contraction mapping in the sup norm with modulus β, so by the Banach fixed-point theorem, iterating V_{n+1} = TV_n converges to the unique fixed point from any starting guess, at geometric rate β. This is why value function iteration (VFI) works — and why it is slow when β is near 1 (the contraction is weak). Policy iteration alternates policy evaluation (solve the linear system for a fixed policy) with policy improvement (greedy update); it converges in finitely many steps for finite MDPs and is typically far faster than VFI, at the cost of solving linear systems. Modified policy iteration (a few evaluation sweeps per improvement) splits the difference. Engineers will recognize all of this: it is exactly RL's dynamic programming (Sutton & Barto Ch. 4), because RL and economic dynamics are the same mathematics.

Discretization: Tauchen and Rouwenhorst

Continuous state variables (productivity shocks, demand states) must be discretized for grid methods. The workhorse is the AR(1) process x′ = ρx + σε, and the two standard discretizations approximate it as a finite Markov chain. Tauchen (1986) builds an evenly spaced grid and sets transition probabilities from the normal CDF evaluated at grid midpoints — simple and accurate for ρ not too close to 1. Rouwenhorst (1995) constructs the chain recursively with a binomial-like structure that matches the conditional variance exactly and stays accurate as ρ → 1, making it the preferred choice for highly persistent processes (income dynamics, productivity). The discipline: always test that your answer is stable as the grid gets denser — if doubling the grid points changes the policy function materially, your solution is a grid artifact, not economics.

Function approximation: beyond grids

Grids suffer the curse of dimensionality: a d-dimensional state with n points per dimension needs n^d grid points. Three escapes. Projection/collocation methods approximate V(s) ≈ Σ_k c_k φ_k(s) with basis functions (Chebyshev polynomials are standard — near-minimax approximation on bounded intervals) and solve for coefficients c_k by forcing the Bellman residual to zero at collocation nodes. Perturbation methods take Taylor expansions around the deterministic steady state — first order gives the linearized solution (the macro workhorse), higher orders capture risk and nonlinearities; fast and scalable, but local (inaccurate far from the steady state). Sparse grids and Smolyak constructions push grid methods a few dimensions further. The choice is problem-dependent: perturbation for smooth macro models near steady state, projection for global nonlinearities in low dimensions, discretization + VFI for discrete-choice problems where the expectation structure is simple.

Computing equilibria of games

BEPP 9310 emphasizes computing equilibria, not just single-agent problems. For dynamic oligopoly, the Ericson–Pakes framework models firms with evolving states (capacity, productivity) playing a Markov perfect equilibrium: each firm's policy depends only on the payoff-relevant state, and beliefs about rivals' play are consistent. Computation iterates best responses (or solves the system of Bellman equations jointly); multiplicity is endemic, so report the equilibrium selection rule you impose (e.g., the limit of a specific learning or entry process). The BLP contraction mapping (Berry, Levinsohn, and Pakes 1995) is the canonical inner loop of structural IO: given demand parameters, the mapping δ′ = δ + log(s_observed) − log(s_predicted(δ)) is a contraction whose fixed point δ recovers the mean utilities that rationalize observed market shares — nested inside an outer GMM optimization over the nonlinear parameters. This inner-loop/outer-loop structure (contraction inside optimization) recurs across structural estimation.

Simulation-based estimation: taking models to data

When the likelihood is intractable (latent states, complex game equilibria), simulate. The simulated method of moments (SMM; McFadden 1989; Pakes and Pollard 1989): pick moments m(θ) the model should match, simulate the model at candidate θ to get m̂(θ), and minimize (m_data − m̂(θ))′W(m_data − m̂(θ)). Indirect inference is the sibling: estimate an auxiliary (misspecified but easy) model on real and simulated data, and choose θ to match the auxiliary parameters. Both need the binding function (θ → simulated moments) to be informative — identification must be argued, not assumed; show that moments move with parameters.

For dynamic discrete choice (Rust 1987's bus-engine replacement is the canonical example), the nested fixed point (NFXP) estimator solves the Bellman equation inside every likelihood evaluation — consistent but expensive. Hotz and Miller (1993) conditional choice probabilities (CCP) avoid re-solving: first-stage nonparametric estimates of choice probabilities, inverted through the Hotelling-style mapping between values and probabilities, recover the value-function differences without fixed-point iteration — fast, at the cost of first-stage noise propagating. The modern frontier (and the QuantEcon differentiable-economics lectures) uses automatic differentiation through the model's solution to get gradients for estimation and counterfactuals — the same AD you use to train neural nets, applied to economic structure.

QuantEcon workflows

QuantEcon (Sargent and Stachurski) is the open laboratory for all of the above, in Python and Julia: discrete-state dynamic programming (value/policy iteration coded cleanly), LQ control (Riccati equation solutions), optimal stopping, and differentiable economics. The recommended workflow: (1) write the recursive formulation on paper; (2) prototype in QuantEcon-style code with a coarse grid; (3) verify contraction/convergence diagnostics and grid-stability; (4) refine (denser grid, better approximation, or perturbation) until the economics stops moving; (5) only then estimate. Most numerical failures in economics are formulation failures — a Bellman equation written wrong converges beautifully to the wrong answer.

Worked examples

Example 1: Optimal GPU-cluster replacement (Rust-style)

You manage a GPU cluster; each month you choose: keep the current hardware (pay rising maintenance/failure cost c(s) increasing in age-state s) or replace (pay fixed cost R, reset age to 0). This is Rust (1987)'s bus problem with GPUs. States: age s ∈ {0,…,S}; actions: keep/replace; transitions: age increments unless replaced; per-period costs as above; discount β = 0.99. The Bellman equation: V(s) = max{ −c(s) + βE[V(s′)|keep], −R + βV(0) } (+ logit shocks ε for the CCP variant). Value function iteration: start V₀ = 0, iterate V_{n+1} = TV_n until sup-norm change < 10⁻⁶. The optimal policy is a threshold: replace iff s ≥ s* — the (s,S)-style rule. With c(s) = 2s² (thousands $) and R = 50, s* ≈ 5 months: replace when cumulative failure risk justifies the capex. The code below solves it; the threshold policy is the deliverable, not the value function.

import numpy as np
S, beta, R = 12, 0.99, 50.0
c = 2.0 * np.arange(S + 1) ** 2          # maintenance cost by age-state
V = np.zeros(S + 1)
for _ in range(10_000):
    keep = -c + beta * np.append(V[1:], V[-1])  # age+1, capped
    repl = -R + beta * V[0]
    Vn = np.maximum(keep, repl)
    if np.max(np.abs(Vn - V)) < 1e-8:
        break
    V = Vn
policy = np.where(-R + beta * V[0] > -c + beta * np.append(V[1:], V[-1]),
                 "replace", "keep")
print("Optimal policy by age:", dict(enumerate(policy)))

Example 2: Discretizing a demand shock (Tauchen vs. Rouwenhorst)

Your data-center demand follows log-demand x′ = 0.95x + 0.1ε (highly persistent, ρ = 0.95). You need a 7-state Markov chain for a capacity-planning DP. Tauchen with 7 points: grid ±3σ_x, transitions from Φ((grid_j − ρ·grid_i ± step/2)/σ_ε). With ρ = 0.95 the Tauchen chain understates persistence at coarse grids — the stationary distribution piles at the edges. Rouwenhorst's recursive construction matches E[x′|x] and Var(x′|x) by construction and stays accurate as ρ → 1. Practical rule from the literature: use Rouwenhorst whenever ρ > 0.9 or grids are coarse; always compare the chain's implied stationary variance σ_x² = σ_ε²/(1−ρ²) against the target. Then solve the DP on both chains: if the capacity policy differs, the discretization — not the economics — is deciding, and you need more points. QuantEcon implements both (quantecon.markov.tauchen, quantecon.markov.rouwenhorst); the five-line comparison is the cheapest robustness check in computational economics.

Example 3: SMM estimation of a dynamic pricing model

You model a SaaS firm's dynamic pricing: state = (current price tier, demand shock), action = adjust or hold price (menu cost κ). Parameters θ = (κ, demand persistence ρ, price sensitivity η) are unknown. SMM: choose moments — (a) frequency of price changes, (b) average absolute size of changes, (c) autocorrelation of the price level, (d) covariance of price with a demand proxy. Simulate the solved model at θ, compute the same moments, minimize the weighted distance. Identification logic (state it before estimating): moment (a) pins down κ (higher menu cost → fewer changes); (b) pins down the interaction of κ and shock variance; (c) pins down ρ; (d) pins down η. If two parameters move moment (a) identically, you're underidentified — add a moment or admit it. Weighting matrix W: start with identity, then two-step optimal W = inverse covariance of moments. The output isn't just θ̂ — it's θ̂ with standard errors and an overidentification J-test telling you whether the model can fit all moments at once (rejection = misspecification, a feature, not a bug).

Key results to remember

  • Write states, actions, transitions, and the Bellman equation before coding; the Bellman operator is a contraction (modulus β) — VFI converges geometrically (Stokey–Lucas–Prescott).
  • Value function iteration is robust but slow near β = 1; policy iteration is fast but solves linear systems; modified policy iteration splits the difference.
  • Discretize AR(1) shocks with Tauchen (simple) or Rouwenhorst (accurate for ρ near 1); always check grid-stability of the answer.
  • Curse of dimensionality → projection/collocation (global, low-d), perturbation (fast, local), sparse grids; match the method to the problem's smoothness and dimension.
  • Ericson–Pakes for dynamic oligopoly / Markov perfect equilibria — expect multiplicity; report your selection rule.
  • BLP contraction mapping: the inner loop that recovers mean utilities from market shares; the template for contraction-inside-optimization.
  • NFXP (Rust) re-solves the DP per likelihood step; CCP (Hotz–Miller) avoids it via first-stage choice probabilities; SMM/indirect inference match simulated moments when likelihoods are intractable.
  • QuantEcon (Python/Julia) is the open reference implementation; Judd (1998) and Miranda & Fackler (2002) are the canonical texts.

Check your understanding

  1. Your VFI converges but the optimal policy changes when you double the grid density. What went wrong, and what do you do?
    Answer

    The solution is a grid artifact, not the economics — discretization error dominates. Do: increase grid density (especially where the policy function has kinks, like the replacement threshold), try Rouwenhorst if shocks are persistent, or switch to a global approximation (collocation with Chebyshev polynomials) that doesn't depend on grid coarseness. Don't: report the coarse-grid policy.

  2. When would you choose the CCP estimator over nested fixed point for a dynamic discrete-choice model, and what do you give up?
    Answer

    Choose CCP when the state space is large and re-solving the Bellman equation per likelihood evaluation (NFXP) is prohibitively expensive — CCP's first-stage choice-probability estimates let you invert for value differences without fixed-point iteration. You give up: finite-sample precision (first-stage nonparametric noise propagates into θ̂), and robustness — CCP needs the first stage to be well-estimated in all relevant states, which fails with sparse data.

  3. Explain the structural similarity between the BLP contraction mapping and value function iteration.
    Answer

    Both iterate a contraction mapping to a unique fixed point: VFI iterates the Bellman operator T (modulus β) to get the value function; BLP iterates δ′ = δ + log(s_obs) − log(s_pred(δ)) (a contraction in the sup norm) to get the mean utilities rationalizing observed shares. In both, Banach's theorem guarantees convergence from any start, the fixed point is the economically meaningful object, and the iteration typically sits inside an outer loop (policy improvement / GMM over nonlinear parameters).

  4. A colleague says "I'll estimate my dynamic game by SMM with 3 moments and 8 parameters." What's the problem?
    Answer

    Underidentification: 3 moments cannot pin down 8 parameters — the binding function θ → moments has a 5-dimensional null space, so the SMM objective is flat along it and θ̂ is meaningless (standard errors will be enormous / the optimizer wanders). Fix: add informative moments (need at least as many independent moment conditions as parameters), calibrate some parameters from outside evidence, or simplify the model. Always argue identification — which moment moves which parameter — before estimating.
